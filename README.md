# ✅ To-Do List App

A simple and interactive To-Do List application built using **HTML, CSS, and JavaScript**.  
This app allows users to add, edit, complete, and delete tasks with data saved using LocalStorage.

---

## 🚀 Features
- Add new tasks
- Mark tasks as completed
- Edit task using double click
- Delete tasks
- Data saved using LocalStorage
- Tasks remain after page refresh

---

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)
- LocalStorage API
